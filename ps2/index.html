Before you upload

The second-to-last page of the PDF is a 60-second checklist. The short version:

  • Open the PDF you are about to upload — the file itself, not your working document — and read it to the last page.
  • Every lettered part should have an answer under it. Problem 1 runs (a)–(k), Problem 2 (a)–(h), Problem 3 (a)–(e), Problem 4 (a)–(i), plus the total-time estimate at the end.
  • If an answer says “see separate file,” make sure that file is attached to the same Canvas submission.
  • If you regenerated from the answer builder, check that the file you are uploading is the highest-numbered one. Its version is on the first page.
  • If a number came out different from what you expected, say so in a sentence rather than leaving it. An unremarked surprise costs points; a remarked one often earns them.

The posted PDF is a page-image copy, so there is no text in it to select. That is deliberate: the prompts you give an AI on this set should be written by you, in your own words, because that is most of what the set is teaching.
